# Marketing kit

This folder is **not published** (Netlify returns 404 for `/marketing/*`, and robots.txt disallows it). It holds ready-to-use material:

| File | What it is |
| --- | --- |
| `copy.md` | Taglines, social posts, Product Hunt, Show HN, Reddit framings, a developer article outline, a video script and an outreach email |
| `ads.md` | Google, Reddit and Meta ad copy with keywords, negatives and UTM links (character limits checked) |
| `seo-checklist.md` | The account-level steps that only you can do (Search Console, GitHub settings, licence) |
| `social/` | Images: three 1080x1080 squares and a 1500x500 banner; plus the GitHub social preview |

What is **not** done: nothing has been posted, submitted or paid for. Those actions need your accounts and, for ads, a budget. The kit is written so you can copy, paste and go.

Rebuild the images any time with `python3 tools/make_assets.py <screenshots-dir> <flutter-material-fonts-dir>`.
