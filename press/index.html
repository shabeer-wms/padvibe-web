About PadVibe

One line: PadVibe is a free, open source soundboard for macOS, Windows and Linux, built for podcasters, streamers and live shows.

Short description: PadVibe lets you drop audio files onto colourful pads and play them instantly with a click, a keyboard key, a MIDI controller or a URL. It offers MIDI learn with RODECaster Pro support, mixer faders, per-pad output routing, level meters, a countdown timer and a local HTTP API.

Key facts

  • Price: free, no account.
  • Platforms: macOS (Apple Silicon and Intel), Windows 10 and 11, Linux.
  • Formats: MP3, WAV, OGG, FLAC.
  • Built with: Flutter, with a Python audio and MIDI engine.
  • Source: github.com/shabeer-wms/padvibe
  • Contact: open an issue on GitHub.
