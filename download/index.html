Install on macOS with Homebrew

If you use Homebrew, one command installs PadVibe and keeps it updatable:

brew tap shabeer-wms/padvibe
brew install --cask padvibe

First launch

The first time you open a new version, macOS checks the app, so it can take about 15 seconds to start. Later launches take about a second.

"Cannot be opened because the developer cannot be verified"? PadVibe is not yet signed with a paid Apple Developer certificate. Right-click PadVibe in Applications, choose Open, then confirm. Or run xattr -dr com.apple.quarantine /Applications/PadVibe.app in Terminal.
Windows SmartScreen. Choose More info, then Run anyway.

Linux notes

Install GTK 3 and an audio stack (ALSA, PulseAudio or PipeWire). Then extract the archive and run ./bundle/pads.

System requirements

  • macOS 10.15 or later (Apple Silicon or Intel), Windows 10 or 11 (64-bit), or a 64-bit Linux desktop.
  • Roughly 100 to 250 MB of disk space depending on the platform, plus your audio files.
  • An audio output device. MIDI is optional.

Your data stays with you

PadVibe needs no account and makes no network requests to use. Read the privacy page.

FAQ

Download questions

Is PadVibe free to download?

Yes. It is free, with no account or subscription.

Why does macOS or Windows warn me when I open it?

PadVibe is not yet code-signed with a paid developer certificate, so the system asks you to confirm. On macOS, right-click the app and choose Open. On Windows, choose More info, then Run anyway.

Which macOS version do I need?

PadVibe is built for macOS 10.15 (Catalina) and later, on Apple Silicon and Intel Macs. It has been tested on macOS 15 and 26. If a download will not open, tell us on GitHub.

Where does PadVibe store its data?

In your user account's application support folder: your pad layout, a copy of your audio files and log files. Nothing is sent anywhere.
